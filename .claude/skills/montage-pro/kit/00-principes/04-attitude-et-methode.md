# Attitude et méthode de travail

- **Ne jamais dire « impossible » ou « pas encore fait » sans avoir essayé au moins 3 méthodes.**
  Relire le journal d'abord : on l'a peut-être déjà fait (ex. détourage déjà fait sur la pub Valex).
- **Vérifier avant de livrer** : planche contact avant le rendu complet (évite chevauchements, débordements),
  réécoute du début, mesure du loudness.
- **Ne jamais fabriquer de preuve** : pas de faux chiffres, faux clients, faux messages. Si le site a des
  « études de cas », demander confirmation que ce sont de vrais clients avant de les montrer.
- **Regarder chaque ressource téléchargée** (logo, capture) avant de l'utiliser.
- **Analyser une inspiration = image + son + CTA/légende**, pas seulement l'image.
- **Annoncer la durée finale** de la vidéo clairement (ne pas confondre avec le temps de rendu).
- **Faire grandir le savoir** : après chaque projet, une entrée au journal ; une leçon répétée devient une règle.

## Déroulé type d'un projet
1. Récupérer la source + transcrire mot à mot (horodatage).
2. Identifier le type de vidéo → choisir la recette (`02-recettes-par-type/`).
3. Couper les silences (sur l'énergie du signal), écrire le plan de montage (phrase → écran).
4. Construire l'image (HTML render(t) ou Python/PIL), planche contact, corriger.
5. Construire le son (musique, bruitages calés sur les événements), mixer, -14 LUFS.
6. Rendu, vérification checklist, copie légère 720p pour WhatsApp.
7. Légendes + hashtags par plateforme.
8. Journal.

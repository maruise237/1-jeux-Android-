# Règle mère : choisir les techniques selon le type de vidéo

Les techniques ne vont pas sur toutes les vidéos. Une technique qui marche dans un type peut faire
« slop IA » dans un autre. **Avant de monter : identifier le type de vidéo, puis piocher dans SA ligne.**
Jamais le même traitement par défaut (ex. fond assombri + texte derrière) sur chaque vidéo.

| Type de vidéo (référence) | À utiliser | À éviter |
|---|---|---|
| **Tuto outil / astuce** (Toprak, Med, Loucash) | Vraies captures + curseur, logo officiel de chaque outil cité, numéro d'étape 1/2/3, fond clair entre les captures | Mèmes en série, B-roll décoratif, longs effets : on veut voir l'outil |
| **Vulgarisation / histoire** (Faro) | B-roll au-dessus de la tête, mèmes, cartes-titres de chapitre, étude citée, schéma qui se construit, 1 changement / 2 s | Captures d'écran, numéros d'étape (ce n'est pas un tuto) |
| **Business / preuve** (Wu) | Couleur de marque, preuve sociale (messages clients, chiffres), B-roll lifestyle, mot géant | Mèmes trop potaches qui cassent la crédibilité |
| **Podcast / interview long** | Multicam simulé, sous-titres propres, texte derrière seulement sur le hook et les chapitres | Texte derrière en continu, un visuel par phrase (fatigant sur 2 min+) |
| **Pub / motion design** (Valex) | Typo animée, couleurs de la marque, voix off qui dicte le rythme | Règles facecam (multicam, sous-titres 1–3 mots) si personne à l'écran |
| **Liste d'outils avec mon produit** (KamForms, Djoumi) | Même format pour chaque outil, mon produit en dernier, vraies captures | « Mon outil », chiffres ou témoignages inventés |

## Conditions par technique
- **Texte derrière la personne** : seulement s'il y a de la place au-dessus de la tête (≥ 15 % de l'écran)
  et pas de mains devant le visage ; 2 à 4 fois par vidéo (hook, chapitres). Le reste du temps : image naturelle.
- **Assombrissement du fond** : léger (×0,45, flou 3 px). Jamais sous ×0,40, sinon on voit le détourage.
- **Multicam simulé** : seulement si tourné sous un seul angle.
- **Mèmes** : seulement si ton détendu et public grand public. Jamais dans une pub client.
- **Captures / logos** : dès qu'un outil, site ou appli est cité.
- **Dans le doute : moins d'effets, mieux choisis.** Un effet doit servir la phrase, pas décorer.

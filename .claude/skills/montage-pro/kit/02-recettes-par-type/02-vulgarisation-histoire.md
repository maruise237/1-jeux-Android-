# Recette : vulgarisation / histoire (1 min 30 – 3 min)

Référence : Fabien Faro (144 k et 107 k likes, la plus grosse audience de nos inspirations).

| Élément | Choix |
|---|---|
| Hook | « Tu savais que des scientifiques… » + 3 promesses concrètes |
| Musique | Épique, forte sous le hook, puis -12 dB ; 2–4 s de musique seule (drop) sur la carte-titre du concept |
| Rythme | **1 changement / 2 s** du début à la fin (obligatoire en long format) |
| Visuels | B-roll au-dessus de la tête qui change à chaque phrase ; B-roll plein écran pour l'abstrait ; mèmes pour l'humour |
| Structure | Cartes-titres de chapitre (CAPITALES + *serif italique*) ; schéma dessiné qui se construit |
| Preuve | Étude datée + revue + photo du chercheur avec nom ; sources en légende |
| Sous-titres | Capitales grasses blanches, 2–3 mots, 1 mot clé fixe en jaune, à ~60 % de la hauteur |
| Bruitages | 20–40/min, impacts graves sur les mots forts |
| Fin | Morale en une phrase + signature fixe + mème ; CTA « commente MOT » recommandé (×100 commentaires) |

À éviter : captures d'écran, numéros d'étape façon tuto.

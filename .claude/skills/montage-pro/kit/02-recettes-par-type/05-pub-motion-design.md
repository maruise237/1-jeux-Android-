# Recette : pub motion design (30–40 s, sans personne à l'écran)

Référence : pub « Valex L'infographiste » (v1 sans voix 36 s, v2 voix off 39 s).

| Élément | Choix |
|---|---|
| Rythme | **La voix off dicte le rythme** : animations calées sur les timestamps des mots |
| Typo | Animée, couleurs de la marque, mot géant par phrase |
| Visuels | Réalisations réelles du client (affiches, logos, mockups), portrait détouré |
| Sous-titres | Synchronisés mot à mot (le mot prononcé peut passer en couleur de marque) |
| Son | Musique ~120 BPM, bruitages synthétisés, voix 9 dB au-dessus de la musique, -14 LUFS |
| Première image | Pleine et déjà en mouvement |
| Fin | Pas de fondu au noir (boucle) ; contact / CTA clair |
| Livrables | Version HD + version légère WhatsApp + textes pour le gestionnaire de publicités |

À éviter : règles facecam (multicam, sous-titres 1–3 mots) ; mèmes.
Pipeline : `04-outils/rendu-html/` (animation.html avec render(t) → images → ffmpeg).

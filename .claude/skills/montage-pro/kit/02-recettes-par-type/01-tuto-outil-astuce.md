# Recette : tuto outil / astuce (30–60 s)

Références : Toprak (22 653 likes), MedTheDesigner, Loucash.

| Élément | Choix |
|---|---|
| Hook | Le résultat ou l'effet lui-même dès la 1re seconde. Son presque sec + pops |
| Musique | Démarre après un riser de 1–1,5 s sur la 1re coupe ; 17–24 dB sous la voix ; texture qui change à chaque étape |
| Rythme | 1 changement / 1,5–4 s |
| Visuels | Vraies captures + curseur + cercle loupe + zoom progressif ; captures dans un cadre de téléphone sur fond clair |
| Logos | Officiels, pop sous le sous-titre à chaque outil cité |
| Repère | Numéro d'étape « 1. / 2. / 3. » persistant en haut à gauche |
| Bruitages | 60–80/min : clics, touches, pops, whoosh 1 coupe sur 2 |
| Texte derrière | Hook seulement |
| CTA | « Abonne-toi, commente MOT et je t'envoie le lien » + champ commentaire qui se tape |

À éviter : mèmes en série, B-roll décoratif, effets longs.

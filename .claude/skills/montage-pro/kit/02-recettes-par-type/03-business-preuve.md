# Recette : business / preuve / émotion (40–60 s)

Référence : Mickaël Wu.

| Élément | Choix |
|---|---|
| Format | 9:16 ou carré 1080×1080 |
| DA | Couleur de marque + blanc cassé (Wu : rouge + crème) |
| Hook | Impératif provocant + chiffres réels |
| Visuels | Mot géant couleur de marque derrière/sur la personne ; texte posé au sol en perspective ; polaroids sur papier |
| Preuve sociale | Captures de vrais messages clients sur téléphone, fond couleur de marque, phrase clé en gros, voix off qui lit |
| B-roll | Lifestyle cinématique (statut) |
| Musique | ~10 dB sous la voix ; **coupée 1,5–3 s sur chaque punchline** |
| Bruitages | Peu (~15/min) |
| Fin | Sur la preuve, sans CTA |

À éviter : mèmes potaches, preuves non vérifiables.

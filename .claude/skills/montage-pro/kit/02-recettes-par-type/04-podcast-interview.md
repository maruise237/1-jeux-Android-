# Recette : podcast / interview (1 min 30 – 2 min 30)

Référence : notre podcast « Mariuse × Claude » (versions 1 min 31 et 2 min 06).

| Élément | Choix |
|---|---|
| Image de la personne | **Naturelle, non assombrie** + multicam simulé (large / serré / gros plan) |
| Texte derrière | Seulement 3–4 fois : hook, changements de chapitre, CTA |
| Sous-titres | 1–3 mots sous le menton ; discrets sur les cartes typo |
| Interlocuteur hors-champ / IA | Motion design typo : une composition par phrase, alternance nuit / papier crème, preuves réelles (transcription, forme d'onde, vrai code, vraies images) |
| Cartes | Le 1er élément apparaît dès la coupe (jamais d'écran vide) |
| Son | Hook sec + riser → musique à la 1re coupe ; musique ~17 dB sous la voix ; coupée sur une phrase intime |
| Bruitages | Sur actions visibles seulement ; rien sur les coupes multicam |
| CTA | Champ commentaire qui se tape avec une question liée au sujet |

À éviter : texte derrière en continu, un visuel décoratif par phrase sur 2 min (fatigant).
Faire deux versions (courte ~1 min 30 / longue ~2 min) si la matière le permet.

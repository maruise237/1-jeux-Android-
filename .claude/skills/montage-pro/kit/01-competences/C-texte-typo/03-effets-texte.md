# Effets de texte

| Effet | Recette |
|---|---|
| **Glow** sur fond sombre | `text-shadow: 0 0 20px rgba(255,255,255,.6)` + serif italique + capitales condensées |
| **Texture vintage / poster** | Fond jaune, Helvetica 75 Bold, opacité texte 85 %, grain (bruit animé), aberration chromatique (décalage RGB 2–4 px), légère pixellisation |
| **Sous-titre négatif** | Texte en masque qui inverse la vidéo dessous (`mix-blend-mode: difference`). CapCut : dupliquer le clip, masque texte, inverser la courbe |
| **Mot qui déborde** | Mot géant plus large que l'écran (« 100% », « sans dépenser ») |
| **Encadré sélection** | Rectangle pointillé + poignées aux coins (look Figma/Canva) |
| **Mot barré** | Trait qui barre le mot faux, le bon mot apparaît à côté |
| **Texte au sol** | Perspective homographique sur le sol de la scène |
| **Étiquette inclinée** | Pastille crème inclinée de 3–6° avec le mot : lisible sur fond chargé |
| **Mot tapé** | Le mot s'écrit lettre par lettre (champ commentaire, recherche) + bruit de touche |

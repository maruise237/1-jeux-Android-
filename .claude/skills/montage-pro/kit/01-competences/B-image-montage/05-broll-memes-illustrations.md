# B-roll, mèmes, illustrations, éléments graphiques

## B-roll au-dessus de la tête (Faro)
Image détourée ou cadre carré dans le tiers haut (y ≈ 8–30 %), par-dessus le décor, sans cacher le visage.
Change à chaque phrase. Apparition sèche ou pop 0,15 s.

## B-roll plein écran
Pour les idées abstraites (cerveau 3D, IRM, neurones, foule floue). B-roll lifestyle cinématique pour
le statut (business). Objets 3D isolés sur papier crème (cerveau, vieille TV, téléphones flottants).

## Mèmes
Seulement si ton détendu + public grand public. Plein écran pour la punchline humour.
Jamais dans une pub client.

## Illustrations avec une DA
Ex. Loucash : aplats **corail #E07A5F + crème + traits noirs** dessinés main, animés (ticket de caisse qui
s'allonge = « la facture », chronomètre, globe). **Une seule DA par vidéo.**

## Éléments graphiques pro
| Élément | Description |
|---|---|
| Carte-titre de chapitre | Plein écran sur fond animé : CAPITALES sans grasses + 1 mot en serif italique condensé (« SYSTÈME *NEUROLOGIQUE* ») |
| Numéro d'étape persistant | « 1. / 2. / 3. » en italique dans le coin haut-gauche pendant tout le point |
| Schéma qui se construit | Trait noir sur fond blanc, un élément ajouté par phrase (RÉSULTAT → ACTION → IDENTITÉ) |
| Encadré « sélection » | Rectangle pointillé avec poignées aux coins (look Figma) autour d'un mot |
| Annotation manuscrite | Orange/rouge : « (ici) », « SAUCE SECRÈTE » entourée |
| Texte au sol | Mot en perspective posé sur le sol du B-roll (homographie 4 points, `PIL.Image.transform(PERSPECTIVE)`) |
| Polaroid | Photo inclinée sur papier blanc cassé + légende minuscule en couleur de marque |
| Letterbox | Vidéo en bande centrale ~16:9, titre dans la bande noire du haut, sous-titre serif dans celle du bas |
